#### Task 1.3 — AutoGenerateAliases 核心方法

- **产出文件**：`internal/config/config.go`
- **函数签名**：
  ```go
  func (c *Config) AutoGenerateAliases(provider Provider) (created []string, updated []string)
  ```
- **逻辑要求**：
  - 若 `!c.IsAutoAliasEnabled()` 直接返回
  - 遍历 `provider.Models`，对每个 model `m`：
    - 查找 alias `m`：
      - 不存在 → 创建新 alias（`AutoGenerated=true`，`Protocol=provider.Protocol`，单 target `{Provider: provider.ID, Model: m, AutoGenerated: true}`），记录到 `created`
      - 存在且 `AutoGenerated=true` 且未 `Locked` 且协议匹配：
        - 若该 provider+model 组合尚未作为 target 存在 → 按 provider 优先级插入 target（`AutoGenerated=true`），记录到 `updated`
    - 手动 alias（`AutoGenerated=false`）或已 `Locked` 的自动 alias → 跳过不修改
  - 返回 `created` 和 `updated` 的 alias 名称列表
- **Target 排序**：在自动 alias 中，targets 按 `ProviderPriority` 排序
- **验证**：`go build ./internal/config/` 通过

#### Task 1.4 — RemoveProviderAutoTargets 清理方法

- **产出文件**：`internal/config/config.go`
- **函数签名**：
  ```go
  func (c *Config) RemoveProviderAutoTargets(providerID string) (emptied []string)
  ```
- **逻辑要求**：
  - 遍历所有自动 alias（`AutoGenerated=true`，未 `Locked`）：
    - 移除 providerID 对应的所有 target
    - 若移除后 targets 为空 → 删除该 alias，记录到 `emptied`
  - 手动 alias 中的 target 保留（即使 provider 已删除），标记 warning
- **验证**：`go build ./internal/config/` 通过

### Step 2: Proxy 层扩展 — 自动 alias + 直接回退路由

- [x] **Step 2 完成**

**完成定义**：`internal/proxy/server.go` 的 `handleProtocolRequest` 在手动 alias 查找失败后，依次尝试自动 alias 查找和直接 provider 回退；所有新增路径通过单元测试。

#### Task 2.1 — Proxy 路由三层 fallback 逻辑

- **产出文件**：`internal/proxy/server.go`
- **修改位置**：`handleProtocolRequest` 函数（约 L456）
- **新逻辑**：
  ```
  1. FindAlias(model) → 手动 alias 查找（现有逻辑，不变）
  2. 未找到 → FindAutoAlias(model) → 自动 alias 查找（新增）
  3. 未找到 → FindProvidersByModel(model) → 直接 provider 回退（新增）
  ```
- **FindAutoAlias 处理**：与手动 alias 相同的 `AvailableTargets` + routing 流程
- **直接回退处理**：
  - 从 `FindProvidersByModel(model)` 结果构造虚拟 targets（每 provider 一个 `Target{Provider: p.ID, Model: model}`）
  - 使用 `AvailableTargets` 过滤后进入正常 routing 流程
  - 日志标记为 `fallback=true`
- **验证**：`go build ./internal/proxy/` 通过

#### Task 2.2 — Proxy 单元测试

- **产出文件**：`internal/proxy/server_test.go`（追加）
- **测试用例**：
  - `TestHandleRequest_AutoAliasFallback`：手动 alias 不存在但自动 alias 存在时正确路由
  - `TestHandleRequest_DirectProviderFallback`：无任何 alias 时通过 provider models 直接路由
  - `TestHandleRequest_ManualAliasPriority`：手动 alias 存在时不被自动 alias 覆盖
  - `TestHandleRequest_AutoAliasDisabled`：自动 alias 禁用时回退到直接 provider 路由
- **验证**：`go test ./internal/proxy/ -run "AutoAlias|DirectProvider|Fallback" -v` 全部通过
